# 项目 3：agent-tools —— 带工具调用的 Agent

## 目标
一个能自主选择工具完成任务的 Agent：联网搜索、本地知识库检索、计算器。

## 功能
1. 定义 3 个工具：web_search（可 mock）、kb_search（复用项目1的索引）、calculator（AST 安全求值）；
2. Agent 循环：模型选工具 → 执行 → 结果回传 → 直到给出最终答案；
3. 最大 8 轮限制；工具报错以字符串回传让模型自适应。

## 技术栈
langchain 1.x `create_agent` + `@tool`（或手写 OpenAI tools 循环）

## 里程碑
- M1 工具定义 + 单工具调用
- M2 多轮工具链（一个问题用上 2 个工具）
- M3 失败回退（工具报错后模型改用其他工具或说明无法完成）
- M4 审计日志（每次工具调用：时间/名称/参数/结果摘要）

## 验收标准
- [ ] "查一下 LangChain 最新版本并算出发布距今多少天" 全自动完成
- [ ] 工具故障时 Agent 不崩溃、能解释原因
- [ ] 无限循环被上限拦截
